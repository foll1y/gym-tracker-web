# GymTracker WebApp (PWA для iPhone и Web) 🏋️‍♂️

Автономное прогрессивное веб-приложение (**PWA**) для ведения тренировок в тренажёрном зале, оптимизированное под Safari и iPhone (поддержка полноэкранного режима Standalone, Dynamic Island, Safe Areas, удержания экрана и работы 100% офлайн).

---

## 🌟 Возможности веб-версии

* **100% Офлайн и приватность**: данные хранятся только на вашем iPhone в локальном хранилище **IndexedDB**. Никаких внешних серверов и обязательной регистрации.
* **📋 Планы и сплиты**: конструктор тренировочных дней, планирование подходов/повторений/весов, быстрое перемещение порядка упражнений и старт тренировки в один клик.
* **🔗 Суперсеты**: связывание любых упражнений тренировки в пары (**A1 + A2**) с цветными бейджами.
* **🏷️ Типы подходов (W, D, F)**: классификация сетов (обычный, разминочный **W**, дропсет **D**, отказной **F**). Разминка не искажает рекорды.
* **📈 Графика прогресса (Canvas)**: интерактивные кривые расчётного 1ПМ и рабочего веса по датам тренировок, фильтры периодов (1м, 3м, 6м, Всё) и карточки рекордов (🏆 PR).
* **🎬 Справочник техники (BottomSheet)**: двухкадровые фото-анимации из базы *free-exercise-db* через быстрый CDN (jsDelivr) с режимами «Сравнение фаз» и «Анимация 1 ↔ 2».
* **📚 База 970+ упражнений**: встроенная энциклопедия на русском языке с поиском на лету и разовой загрузкой в локальную базу.
* **💾 Полная совместимость с Android**: единый формат бэкапа `.json` — тренировки, экспортированные с Android, импортируются на iPhone за пару секунд (и наоборот).
* **📱 iOS Оптимизация**:
  * Запуск с рабочего стола без рамок браузера Safari.
  * Экран не гаснет во время подходов (*Screen Wake Lock API*).
  * Тактильный отклик (*Haptics*).

## 🚀 Как разместить приватно и бесплатно (Cloudflare Pages)

Самый удобный способ: ваш репозиторий на GitHub остаётся **приватным**, а сайт доступен только по вашей личной ссылке.

### Шаг 1: Загрузите проект в приватный репозиторий GitHub
1. Создайте новый репозиторий на [GitHub](https://github.com) (выберите **Private**).
2. Загрузите файлы из этого архива:
   ```bash
   git init
   git add .
   git commit -m "Initial commit GymTracker Web"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/gym-tracker-web.git
   git push -u origin main
   ```

### Шаг 2: Подключите Cloudflare Pages (100% бесплатно)
1. Зарегистрируйтесь на [cloudflare.com](https://dash.cloudflare.com) (бесплатно).
2. В боковом меню перейдите в **Workers & Pages** ➔ нажмите **Create application** ➔ вкладка **Pages** ➔ **Connect to Git**.
3. Выберите ваш приватный репозиторий `gym-tracker-web`.
4. В настройках сборки:
   * **Framework preset**: `None`
   * **Build command**: *оставьте пустым*
   * **Build output directory**: *оставьте пустым (или `. / корень`)*
5. Нажмите **Save and Deploy**.
6. Через 20 секунд сайт готов! Вы получите личный защищённый адрес (например: `https://gym-tracker-xyz.pages.dev`).

## 📲 Как установить на iPhone

1. Откройте полученную ссылку в браузере **Safari** на iPhone.
2. Внизу экрана нажмите кнопку **«Поделиться»** (иконка квадрата со стрелкой вверх).
3. Прокрутите вниз и выберите **«На экран „Домой“»** (Add to Home Screen).
4. Нажмите **«Добавить»**.

Готово! На рабочем столе появится иконка GymTracker. Приложение будет открываться на весь экран и работать без интернета даже в подвальных тренажёрных залах.

## 💻 Локальный запуск на компьютере (для проверки)

Если вы хотите запустить проект локально:
```bash
# Через Python:
python3 -m http.server 8080

# Или через Node.js:
npx serve .
```
Откройте в браузере: `http://localhost:8080`.
